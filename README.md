# Brasa - Pix to Solana

Brazil's fastest bridge from Pix to Solana.

## The Problem
140M Brazilians use Pix daily, but moving from Pix to USDC on Solana is slow, expensive and opaque.

## The Solution
Brasa is an analytics and payments layer that tracks Pix -> Solana flows in real-time, shows best rates, volume and fees.

- MVP: Analytics dashboard for Pix volume on Solana
- V2: Direct Pix on-ramp to receive USDC instantly

## Why Solana?
Fast, cheap, and perfect for micropayments. Ideal for Pix-like experience.

## Tech Stack
- Python for data analysis
- Solana RPC
- Next.js dashboard (coming soon)
